# Learning Roadmap

This page documents my focused learning roadmap for building a stronger AI/Data Engineering portfolio.

## Current direction

My current learning direction combines:

- AI engineering
- Data engineering
- AWS cloud architecture
- MLOps
- GenAI applications
- AML domain use cases
- Product thinking

## Phase 1: Foundation and public visibility

Focus:

- Refresh Python and machine learning foundations
- Publish clean learning notes
- Build small but complete projects
- Improve GitHub hygiene and documentation

Outputs:

- Well-structured GitHub repositories
- Markdown notes
- Small Python scripts
- Beginner-friendly explanations
- LinkedIn posts linked to project pages

## Phase 2: Applied AI/Data Engineering

Focus:

- Move from notes to working prototypes
- Build reusable pipeline examples
- Add AWS architecture thinking
- Introduce MLOps patterns

Outputs:

- Data pipeline examples
- Model evaluation notebooks
- Architecture diagrams
- Case-study style project pages

## Phase 3: Domain-focused portfolio

Focus:

- Apply AI/data skills to AML and compliance workflows
- Create synthetic but realistic domain use cases
- Show techno-functional depth

Outputs:

- AML analytics sandbox
- Risk scoring examples
- Transaction monitoring scenarios
- Explainability notes
- Business-value-oriented project writeups

## Phase 4: Professional positioning

Focus:

- Convert learning artifacts into a career portfolio
- Link GitHub, LinkedIn, and website together
- Demonstrate leadership, clarity, and product thinking

Outputs:

- Portfolio homepage
- Project case studies
